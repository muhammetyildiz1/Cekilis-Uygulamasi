Çekiliş Uygulaması



Terminal üzerinden çalışan bir çekiliş uygulaması. Kullanıcı ekleme, listeleme, listeyi karıştırma ve rastgele kazanan seçme işlemlerini menü üzerinden yapıyor.



Özellikler

Kullanıcı ekle

Kullanıcıları listele

Listeyi karıştır

Rastgele çekiliş yap (istenen sayıda kazanan seçilebilir)



Ortam olarak Python 3 kullanılmıştır, ek bir kütüphane gerekmez.



Çalıştırma



```bash python cekilis.py ```



Program açıldığında aşağıdaki menü karşınıza çıkıyor:



``` 1-Kullanıcı Ekle 2-Kullanıcıları Listele 3-Çekiliş Yap 4-Listeyi Karıştır ```



İlgili işlem için menüden bir numara seçmek yeterli.
