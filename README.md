# Çekiliş Uygulaması

Terminal üzerinden çalışan basit bir çekiliş uygulaması. Kullanıcı ekleme, listeleme, karıştırma ve rastgele kazanan seçme işlemlerini bir menü üzerinden yapıyor.

## Özellikler

- Kullanıcı ekle
- Kullanıcıları listele
- Listeyi karıştır
- Rastgele çekiliş yap (istenen sayıda kazanan seçilebilir)

Ortam olarak Python 3 kullanılmıştır, ek bir kütüphane gerekmez.

## Çalıştırma

```bash
python cekilis.py
```
